# 인지검사 Android 앱

이 저장소는 GitHub Actions에서 자동으로 Android APK를 생성합니다. 컴퓨터에 Android Studio나 SDK를 설치하지 않아도 됩니다.

## 가장 쉬운 APK 생성 방법

1. GitHub에 로그인합니다.
2. 새 저장소를 하나 만듭니다. 저장소 공개 여부는 Public 또는 Private 모두 가능합니다.
3. 이 압축파일의 내용 전체를 저장소 최상위에 업로드합니다.
   - `.github` 폴더도 반드시 함께 올려야 합니다.
   - GitHub 웹 업로드 화면에서 숨김 폴더가 빠지면, 압축을 푼 폴더를 GitHub Desktop으로 올리는 방법이 가장 안전합니다.
4. 저장소 상단의 **Actions**를 누릅니다.
5. 왼쪽에서 **인지검사 APK 만들기**를 선택합니다.
6. 오른쪽의 **Run workflow** 버튼을 누르고 다시 **Run workflow**를 누릅니다.
7. 실행 항목에 초록색 체크가 표시될 때까지 기다립니다.
8. 완료된 실행 항목을 열고 페이지 아래 **Artifacts**에서 **인지검사-APK**를 누릅니다.
9. 내려받은 ZIP의 압축을 풀면 `인지검사.apk`가 있습니다.

## 휴대폰 또는 태블릿에 설치

1. `인지검사.apk`를 Android 기기로 옮깁니다.
2. 파일 앱에서 APK를 누릅니다.
3. 처음 설치할 때는 “이 출처의 앱 설치 허용” 안내가 표시될 수 있습니다.
4. 해당 파일 앱 또는 브라우저에 한해서 설치를 허용한 뒤 다시 설치합니다.

## 자동 빌드

`main` 또는 `master` 브랜치에 파일을 올릴 때도 APK 빌드가 자동으로 실행됩니다.

## APK 위치

GitHub Actions 내부 빌드 결과:

`app/build/outputs/apk/debug/app-debug.apk`

사용자가 받는 파일 이름:

`인지검사.apk`

## 참고

이 APK는 테스트와 내부 배포에 적합한 디버그 APK입니다. Google Play 등록용 AAB 또는 정식 서명 APK는 별도의 서명 키 설정이 필요합니다.
