인지검사 도우미 설치 방법

[안드로이드 Chrome]
1. 이 폴더를 HTTPS 웹서버에 올린 뒤 index.html 주소를 엽니다.
2. 화면의 '앱으로 설치하기' 또는 브라우저 메뉴의 '앱 설치'를 누릅니다.

[iPhone/iPad Safari]
1. index.html이 올라간 HTTPS 주소를 Safari에서 엽니다.
2. 공유 버튼 → 홈 화면에 추가를 누릅니다.

주의
- 로컬 파일을 직접 열면 브라우저 보안 정책 때문에 설치 및 오프라인 기능이 제한될 수 있습니다.
- 음성 종류는 기기에 설치된 한국어 TTS 음성에 따라 달라집니다.
